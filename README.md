# LKYCIC Global Research Radar

Global developments in practice, public projects and academic publications for Urban Heat and Public Space.

Daily collection is scheduled at 07:17 Singapore time through GitHub Actions. GitHub may delay runs or disable inactive schedules; see Actions for the latest outcome.

Use the shared dashboard to search, filter and save developments. Notes and saved flags are stored only in your browser; use Export workspace to transfer them. Click Load latest shared feed to merge new records.

To add or change projects for automatic collection, edit projects.json in this repository. The dashboard Add project and settings controls modify the local browser copy only.

Sources: Crossref and Google News. Relevance is keyword fit, not evidence quality. Classification is provisional; verify claims with original sources. English queries limit coverage. No API keys are required.
